The problem

Miden moves across multiple compatibility surfaces at once.

A build can compile while its lockfile resolves an older SDK family. A web consumer can be noisy if treated like a toolchain owner. A private note can be committed without being delivered or consumable.

Preflight keeps version, role, evidence, and severity in the same decision.

What it checks

A compatibility gate with context.

Static checks stay strict where evidence is deterministic. Unsupported semantics remain review items.

01

Project role

Conservative classification across SDK consumer, contract, wallet, node, tooling, hybrid, and unknown.

02

Version families

Declared dependencies versus resolved lockfiles, release channels, and target profiles.

03

MASM graph

Missing declarations, unreachable modules, moved sources, and bounded package structure.

04

Migration safety

Removed APIs, client-store transitions, private-note readiness, and non-destructive remediation.

05

Semantic evidence

Fee, anchor, note lifecycle, and retry claims labeled by actual proof type.

06

CI outputs

Human-readable output, JSON, and SARIF with no fabricated errors for skipped rules.
